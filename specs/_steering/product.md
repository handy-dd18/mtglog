# 製品方針

## 目的

Teams や Zoom の会議を、会議ツール側の文字起こし機能・録音機能・ボット参加に頼らず、利用者の PC 内だけで文字起こしする。音声もテキストも PC の外へ送らない。

## 利用者と利用場面

- 利用者は本番 PC（Windows 11）で Teams（新 Teams）または Zoom デスクトップクライアントを使う本人 1 名。
- 会議中にアプリを起動しておけば、会議の終了後に話者区分（自分／相手）と時刻つきの文字起こしファイルが手元に残る。

## 会議ツールに依存しないことの意味

会議ツールの API・プラグイン・設定ファイルの内部形式・録音機能を使わない。音声は Windows 側で既に動いている Edge のブラウザー API で取得し、次の 2 系統に分ける。

1. 自分の声: 利用者が選んだヘッドセットのマイクの音。
2. 相手の声: Windows の既定の再生デバイス（ヘッドセット）に出ている音。

会議ツールが何であっても、ヘッドセットに音を出してさえいれば同じ仕組みで扱える。

## 本番 PC での利用条件

本番 PC では Windows 側で独自の実行ファイルを実行できない。そのため、Windows 側に置くものはブラウザーで開く Web ページだけにし、処理はすべて WSL（または Docker）で行う。

## 対象外（初版）

- 相手側の複数話者の区別（話者ダイアライゼーション）。相手側はまとめて「相手」とする。次版で対応する（`specs/speaker-diarization/`）。
- 議事録の要約・アクション抽出。
- macOS / Linux デスクトップ上の会議ツール。
- 会議ツール側のミュート状態との連動。
- 会議の開始・終了の自動検知（記録は手動で開始・停止する）。
- スピーカー利用時のマイクへの回り込み対策（ヘッドセット利用を前提とする）。次版で、スピーカーやスピーカーフォンでの利用にも対応する（`specs/open-audio/`）。
