ほかに分かったこと（本番 PC、2026-10-21）:

- GitHub から clone したソースで、WSL 上で本体が起動した。GPU は使えず、CPU（small）で動いた。モデルを自動で取得できたので、本番 PC の WSL から Hugging Face に接続できる。
- 未解決（重要）: 記録中に自分が話すと、Teams の相手に聞こえる自分の声がロボットのような音になった。会議の相手に影響するので、原因が分かるまで、相手のいる会議では使わない。録音（`me.wav`）も壊れていたかは未確認。当時、Windows のメモリ使用率は 80% を超えていた。その後、スマートフォンを相手役にして記録したときは再現しなかった。CPU・メモリの負荷で Teams の音声処理が遅れた可能性が高い。
- このアプリは、Teams のミュート中もマイクの音を記録する（Edge がマイクを直接開くため）。利用者はミュート中の音を記録しないことを望んでいる。Teams のミュート状態を読み取る方法（サードパーティ製アプリ API）を調べたが、本番 PC の Teams の設定画面に該当する項目がなく、会議中も API のポート（8124）は開いていなかった。本番 PC では Teams のミュート連動はできない。Zoom のミュート連動は、公開の仕組みがないので行わない（利用者の判断）。利用者の判断で、ミュート中の音を除く対応は行わない（2026-10-22）。連動しないことを README と取得ページに明記した。

```bash
cd mtglog && scripts/start.sh
```

前提と起動方法の詳細は `README.md` にある。テストは `cd server && uv run pytest`、`cd web && npm test`（Node.js 20 以降）。
