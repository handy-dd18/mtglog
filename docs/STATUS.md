## 本番 PC について分かっていること

- WSL 上で本体が動く。GPU は使えず、CPU で動く。本番 PC の WSL から Hugging Face と PyPI に接続できる。
- 試用したときのデバイスは、Web カメラのマイクと PC の内蔵スピーカーだった可能性がある（ヘッドセットではない）。初版はヘッドセットの利用を前提にしている。
- 記録中に相手に聞こえる自分の声が劣化したことがある（V4）。原因が確かめられるまで、相手のいる大事な会議では使わない。
- このアプリは、会議ツールのミュート中もマイクの音を記録する。本番 PC の Teams にはミュート状態を外部に知らせる API がなく（設定に項目がなく、会議中もポート 8124 は開いていない）、連動できない。利用者の判断で対応しない（2026-10-22）。README と取得ページに明記した。Zoom のミュート連動も行わない。

## 別の端末で作業を再開するとき

```bash
git clone git@github.com:handy-dd18/mtglog.git
cd mtglog && scripts/start.sh
```

前提と起動方法の詳細は `README.md` にある。テストは `cd server && uv run pytest`、`cd web && npm test`（Node.js 20 以降）。ヘッドレス Chromium での確認（`server/tests/e2e_browser.py`、`e2e_silence.py`）には libasound2 が要る。
